I ended up changing quite a bit of the interface since the first release.

The windows now use a darker, more translucent glass design. I also cleaned up the borders, controls, and window buttons while keeping the original fonts and Chiikawa animations.

There are a few smaller fixes in here too.

### What's changed

- Updated the interface with dark translucent glass surfaces across onboarding, settings, timer bubble, completion toast, and alarm notifications.
- Made buttons, cards, sliders, and selected states consistently translucent while keeping text crisp and readable.
- Tightened corner rounding, removed harsh white outlines, and replaced circular close buttons with minimal hover-aware `×` icons.
- Fixed the Study Timer Play/Pause and Reset buttons getting squished when expanding the custom duration editor.
- Fixed the Settings panel and pet jumping around while dragging the Size slider.
- Improved sprite sharpness on HiDPI displays and at larger pet sizes with native-resolution decoding and outline-preserving scaling.
- Made the onboarding `×` button exit the app during startup onboarding (while still just closing the overlay when replaying the tutorial from Settings).
- Allowed moving the onboarding window by dragging any non-interactive area instead of only the top bar.
- Updated the Windows app icon to match the macOS Chiikawa twirl artwork.

### Downloads

**Windows (64-bit)**
- **Windows Installer (Recommended):** download `ChiikawaStudyPet-Setup-x64.exe`, run it, and launch **Chiikawa** from the Start Menu (installs per-user under `%LOCALAPPDATA%\Programs\Chiikawa`, no admin required; upgrades an existing v1.0.0 install in place while preserving settings).
- **Windows Portable (Optional):** download `ChiikawaStudyPet-Windows-x64.zip`, extract it, and run `ChiikawaStudyPet.exe`.

**macOS 13 (Ventura) or later (Apple Silicon & Intel)**
- **Apple Silicon (M1 / M2 / M3 / M4):** download `ChiikawaStudyPet-macOS-arm64.dmg`
- **Intel Mac (x64):** download `ChiikawaStudyPet-macOS-x64.dmg`

Open the DMG and drag `ChiikawaStudyPet.app` into **Applications**.

This is still a small personal project, so there may be a few things I've missed.

### Notes

- **Windows SmartScreen:** The Windows installer and executable are not code-signed yet, so Microsoft Defender SmartScreen may show "Windows protected your PC" the first time you run them. Click **More info**, then **Run anyway**.
- **macOS Gatekeeper:** The macOS builds are ad-hoc signed and not notarized with an Apple Developer ID yet, so Gatekeeper may block the first launch. To open it:
  1. Verify the download: `shasum -a 256 ~/Downloads/ChiikawaStudyPet-macOS-*.dmg` and compare with `SHA256SUMS.txt`.
  2. Drag `ChiikawaStudyPet.app` into **Applications**, double-click it, and click **OK**.
  3. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the ChiikawaStudyPet message.
  4. If there is no **Open Anyway** button, run `xattr -dr com.apple.quarantine /Applications/ChiikawaStudyPet.app` in Terminal, then open the app from Applications. Only do this for the official download.
- **macOS version:** Targets macOS 13 (Ventura) and later.
- **Desktop-Only Mode:** Currently supported on Windows only (disabled on macOS).
- **Checksums:** Verify downloads with `SHA256SUMS.txt`.
