This one is mostly about Quick Actions.

Double-clicking Chiikawa used to just show a little settings gear. Now it opens a small arc of shortcuts around him, so I can jump into Spotify, Discord, League, or Cursor without digging through the Start Menu. You can swap those out for your own apps too, since everyone's "I'll just open one thing" app is different.

I also moved a lot of code around behind the scenes and fixed some window behavior that had been bugging me.

### What's changed

- **Quick Actions menu:** double-click Chiikawa to open a curved menu of shortcuts that follows his sprite. Click outside it or double-click again to close it. He stops wandering and switching animations while it's open.
- **Default shortcuts:** Spotify, Discord, League of Legends, Cursor, Settings, and Exit. If an app is already running, it gets brought to the front instead of opening a second copy.
- **Customizable shortcuts:** Settings now has its own **Quick Actions** section. You can turn shortcuts on or off, drag them into a different order (or use Move Up / Move Down), rename them, change their icons, remove them, add your own apps (up to 16 shortcuts), and restore the defaults.
- **Adding apps:** the Add / Edit window lists your installed apps with icons and a search box. It shows the apps you'd probably want first, with a **Show all applications** checkbox for everything else, plus **Browse…** if something isn't listed. Uninstallers, docs, and system tools are still findable by searching, they just aren't in the way.
- **Icon size slider** for the Quick Actions menu (80%–150%).
- **Settings and Chiikawa move separately now.** Settings still opens next to him, but after that you can drag either one without dragging the other, and his wandering doesn't drag Settings along.
- The Add / Edit shortcut window is its own draggable window, so Settings stays usable while it's open. Closing Settings closes it without saving half-finished edits.
- Shortcut checkboxes match the Pet Preferences checkboxes now.
- Reorganized the source code into folders by feature (`app`, `pet`, `quickactions`, `timer`, `alarm`, `ui`, `platform`). This doesn't change anything you'll see, but it's a lot easier to work on.
- Running the tests no longer touches your real saved settings.

Your existing settings carry over when you upgrade from v1.1.0.

### Downloads

**Windows (64-bit)**
- **Windows Installer (Recommended):** download `ChiikawaStudyPet-Setup-x64.exe`, run it, and launch **Chiikawa** from the Start Menu (installs per-user under `%LOCALAPPDATA%\Programs\Chiikawa`, no admin required; upgrades an existing v1.1.0 or v1.0.0 install in place while keeping your settings).
- **Windows Portable (Optional):** download `ChiikawaStudyPet-Windows-x64.zip`, extract it, and run `ChiikawaStudyPet.exe`.

**macOS 13 (Ventura) or later (Apple Silicon & Intel)**
- **Apple Silicon (M1 / M2 / M3 / M4):** download `ChiikawaStudyPet-macOS-arm64.dmg`
- **Intel Mac (x64):** download `ChiikawaStudyPet-macOS-x64.dmg`

Open the DMG and drag `ChiikawaStudyPet.app` into **Applications**.

This is still a small personal project, so there may be a few things I've missed.

### Notes

- **Windows SmartScreen:** The Windows installer and executable are not code-signed yet, so Microsoft Defender SmartScreen may show "Windows protected your PC" the first time you run them. Click **More info**, then **Run anyway**.
- **macOS Gatekeeper:** The macOS builds are ad-hoc signed and not notarized with an Apple Developer ID yet, so Gatekeeper may block the first launch. To open it:
  1. Verify the download: `shasum -a 256 ~/Downloads/ChiikawaStudyPet-macOS-*.dmg` and compare with `SHA256SUMS.txt`.
  2. Drag `ChiikawaStudyPet.app` into **Applications**, double-click it, and click **OK**.
  3. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the ChiikawaStudyPet message.
  4. If there is no **Open Anyway** button, run `xattr -dr com.apple.quarantine /Applications/ChiikawaStudyPet.app` in Terminal, then open the app from Applications. Only do this for the official download.
- **Custom apps:** On Windows you can add `.exe` files and `.lnk` shortcuts. On macOS you can add `.app` bundles. Store apps that don't have a Start Menu shortcut, and games that Steam or Epic add as web-link shortcuts, won't show up in the list yet.
- **Tutorial:** The startup tutorial still shows the old settings gear for double-click. Double-click opens Quick Actions now, and Settings is one of the shortcuts.
- **macOS testing:** The macOS builds are compiled, tested, and launch-checked automatically, but I've done most of my hands-on testing on Windows, so Quick Actions on a real Mac haven't been tried as much.
- **macOS version:** Targets macOS 13 (Ventura) and later.
- **Desktop-Only Mode:** Currently supported on Windows only (disabled on macOS).
- **Checksums:** Verify downloads with `SHA256SUMS.txt`.
